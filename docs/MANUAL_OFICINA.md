# Manual de uso para oficina

## Entrar

Abra la URL HTTPS en Edge o Chrome, escriba usuario y contraseña. Si falla varias veces, espere el periodo indicado o contacte con administración.

## Crear un trabajo

1. Pulse **Trabajos** y **Nuevo trabajo**.
2. Complete obra/hotel, cliente, tela y valores generales.
3. Añada habitaciones manualmente o use **Importar .xlsx** / **Pegar desde Excel**.
4. Revise las filas marcadas; ancho y altura son metros, aceptan coma decimal.
5. Compruebe tabla de cortes, hoja de confección y croquis.
6. Use **Historial** para confirmar cambios.

El guardado es central. Si otra persona cambió el trabajo, se mostrará conflicto y debe recargar/revisar; el sistema no sobrescribe automáticamente.

## Importar Excel

1. Seleccione `.xlsx` o `.xls` de hasta 5 MB.
2. Elija hoja y fila de encabezados.
3. Revise la asignación de Habitación, Ancho, Altura, Fruncido, Bajo, Hojas, Observaciones y Estado.
4. Elija **Añadir** o **Reemplazar**.
5. Examine la vista previa: las filas rojas no se importan y explican el motivo.
6. Pulse **Importar filas**.

Se reconocen español/inglés, columnas en otro orden, coma/punto y sufijos `m`, `cm`, `mm`. Las celdas combinadas se expanden antes de validar.

## Crear una orden

Cuando todas las habitaciones sean válidas, abra **Órdenes de corte** y cree la orden. El servidor:

- verifica la versión;
- numera la orden;
- congela las medidas;
- bloquea el trabajo.

No podrá editar medidas bloqueadas. Un administrador puede reabrir con motivo mientras la orden no esté en proceso/finalizada; después se crea una revisión nueva.

## Papelera e historial

**Eliminar** mueve el trabajo a la papelera. **Restaurar** requiere permiso. El historial muestra usuario, fecha, acción y valores; no se edita desde la interfaz.

## Impresión

Use el documento adecuado: relación, cortes, confección, croquis o todo. Confirme orientación/márgenes en la vista previa. La impresora es la del ordenador local.

## Buenas prácticas

- No comparta usuarios.
- Cierre sesión al abandonar el puesto.
- No duplique habitaciones.
- Confirme unidades antes de importar.
- No reabra una orden sin explicar el motivo.
- Si aparece un conflicto, no copie datos antiguos sobre la versión nueva.
