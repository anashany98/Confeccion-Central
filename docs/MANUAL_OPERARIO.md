# Manual ultra simple del operario

1. Abra **Confección Central**.
2. Entre con su usuario de corte.
3. Trabaje primero con **Siguiente orden**.
4. Pulse **Ver medidas** para comprobar habitaciones y paños.
5. Pulse **Imprimir todo**. En Edge/Chrome confirme la impresora A4 local y pulse **Imprimir**.
6. Pulse **Confirmar recibida**.
7. Cuando empiece, use la acción disponible de proceso si aparece.
8. Al terminar toda la orden, pulse **Finalizar corte** y confirme.
9. Pulse **Actualizar** si no aparece una orden nueva.
10. Al acabar el turno, pulse **Salir**.

No edite medidas ni use una cuenta de oficina. Si una medida parece incorrecta, detenga la orden y avise a oficina/administración; la incidencia estructurada está prevista para una actualización.

La orden superior es la pendiente más antigua. Las reimpresiones quedan registradas. La impresora utilizada es la predeterminada del PC; no imprime desde el servidor.
