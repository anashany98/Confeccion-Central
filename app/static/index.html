Código ZPL para Zebra

Formato nativo de impresora de etiquetas (ZPL). El tamaño de etiqueta es el elegido en el toolbar (arriba). La forma más directa es el botón «Enviar a Zebra» (requiere el agente local scripts/zebra_agent.py <IP> corriendo en el PC del taller). Alternativas: descarga el archivo y envíalo con python scripts/send_zpl.py <IP> etiquetas.prn (puerto 9100), o imprime el archivo desde Windows con la Zebra instalada (ZDesigner).
